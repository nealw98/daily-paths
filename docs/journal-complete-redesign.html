Design Changes from Current Build
1. Teal header on every screen. The form screens now carry the same gradient header as the timeline and the Today reading screen. Entry type icon and title sit in the header bar. A thin colored strip below the header reinforces which type you're in.

2. No more emoji. Every icon is a custom SVG: feather (journal), seedling (gratitude), soft exhale (spot check), moon-on-water (nightly review). They render in each type's color or in white when on the teal header.

3. Forms breathe more. Pearl background instead of the tinted green. White prompt cards with generous padding. Textareas start on pearl and shift to white on focus — subtle but makes the active field feel alive.

4. Bigger intro text. The italic Cormorant Garamond intro ("Pause. Breathe. Work through what's happening.") is now 19px with a proper border below it. It's a moment of pause before writing, not an afterthought.

5. Prompt questions are 16px. Bigger, bolder. These are important questions — they should feel weighty, not like form labels.

6. Gratitude uses the seedling icon. Warm brown seedlings replace the yellow sparkle emoji. The remove button is a subtle pearl circle with an X, not a distracting colored button.

7. Journal form is just a blank page. No questions accordion — the structured entry types handle guided reflection now. Just a big open textarea and a placeholder.
